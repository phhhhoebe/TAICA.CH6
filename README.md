日和代購 HIYORI（TAICA 作業）

日本代購 Web App 的互動原型，使用 Claude Design 設計，以行動版為主要體驗。

🔗 線上預覽：https://phhhhoebe.github.io/TAICA.CH6/

本專案為示範原型，所有商品、訂單、匯率與轉帳資訊皆為假資料，不會產生任何實際交易。

專案簡介

日和代購是一個協助台灣使用者購買日本商品的代購服務介面。使用者可以參加代購者發起的「開團」，也可以上傳圖片委託報價；費用採「一補＋二補」兩階段收取，讓使用者清楚知道下單當下與商品抵台後各需支付多少。

主要功能
頁面	說明
逛商品	本期主打開團、截團倒數、分類篩選與排序（即將截團／最新上架／價格）
商品詳情	日幣與台幣換算、限購數量、剩餘名額、規格選擇
購物車	自動計算商品小計、代購費、日本國內運費，並預估二補金額
結帳	收件資訊、台灣取貨方式、缺貨處理偏好、費用明細與關稅提醒
委託報價	上傳商品圖片、填寫預算與希望到貨時間，表單自動保留草稿
我的報價	查看報價狀態，可接受、婉拒或重新詢價
我的訂單	訂單進度時間軸、待處理事項、一補／二補付款狀態
須知	運費試算器、代購流程、常見問題與聯絡方式

右下角的 DEMO 面板可模擬代購者端的操作（例如回覆報價、更新訂單進度），方便展示完整流程。

費用計算方式
一補（下單時付款）：商品金額＋代購費（10%，最低 NT$50）＋日本國內運費
二補（抵台後付款）：國際運費（依重量）＋台灣運費＋關稅（商品金額超過 NT$2,000 時可能產生）
